Guide

About BCU Map

Welcome to the BCU Map repository.

You can browse available maps and download their BCUZIP files.

How to Download

1. Select Start.

2. Select a map.

3. Read the map information.

4. Select Download.

Things You Should Not Forgot

If the Maps Didnt load perfectly, Reset the Page. It's affectless to your settings.

Update & Change

Update means that a new version of the map has been uploaded.

Change means that the map itself has been changed.

가이드

BCU Map 소개

BCU Map 저장소에 오신 것을 환영합니다.

다양한 맵을 둘러보고 해당 맵의 BCUZIP 파일을 다운로드할 수 있습니다.

다운로드 방법

1. Maps를 선택합니다.

2. 원하는 맵을 선택합니다.

3. 맵 정보를 확인합니다.

4. Download를 선택합니다.

참고

맵이 제대로 안 불러와지는 경우엔 새로고침을 하십시오. 설정은 그대로 유지됩니다.

Update & Change

Update는 맵의 새로운 버전이 업로드되었음을 의미합니다.

Change는 맵 자체가 변경되었음을 의미합니다.
